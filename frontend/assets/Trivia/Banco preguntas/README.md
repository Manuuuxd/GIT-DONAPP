# 🧠 Banco de Preguntas de Trivia – Donación de Sangre

Este repositorio contiene el banco oficial de preguntas para la trivia educativa sobre donación de sangre.  
Toda la información está en **lenguaje humano**, organizada de manera que cualquiea pueda **copiar, adaptar e implementar** fácilmente en la lógica de su módulo correspondiente.
